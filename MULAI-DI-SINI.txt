SALES PERFORMANCE DASHBOARD - PAKET LOCALHOST
================================================

File ini adalah petunjuk untuk penerima paket. Pengembang dapat membuat ulang
arsip distribusi dengan menjalankan BUAT_PAKET_KLIEN.bat.

KEBUTUHAN KOMPUTER
1. Windows 10/11.
2. XAMPP terpasang di C:\xampp.
3. Node.js LTS versi 20 atau lebih baru.
4. Internet hanya diperlukan saat instalasi pertama untuk npm install.

INSTALASI PERTAMA (HANYA SEKALI)
1. Jangan mengubah atau memindahkan isi folder data-awal.
2. Klik dua kali INSTALL_DASHBOARD.bat.
3. Isi username dan password admin ketika diminta.
4. Tunggu sampai proses selesai. Proses awal dapat memerlukan beberapa menit.
5. Installer membuat database, seluruh tabel, mengimpor tiga Excel, melakukan build,
   membuat shortcut Desktop, dan membuka dashboard.

PEMAKAIAN HARIAN
- Klik shortcut "Buka Sales Dashboard" di Desktop.
- Alamat utama: http://localhost:3210/dashboard
- Jika port 3210 dipakai aplikasi lain, launcher otomatis memilih 3211-3219.
- Browser akan dibuka otomatis pada alamat yang benar.
- Untuk berhenti, klik shortcut "Tutup Sales Dashboard".
- Jika ada beberapa salinan dashboard, setiap salinan memakai port berbeda dan
  tidak akan membuka akun/database milik folder lain.

UPLOAD EXCEL
- Login Admin lalu buka menu Import Excel/CSV.
- File XLSX/CSV maksimal 15 MB.
- Klik Analisis File terlebih dahulu. Data belum masuk sebelum dikonfirmasi.
- Nama sheet, urutan kolom, dan posisi header boleh berubah sampai baris ke-100.
- Jika nama kolom baru belum dikenali, pilih pemetaan lewat dropdown satu kali.
  Format tersebut disimpan dan otomatis dikenali pada upload berikutnya.
- Mode Tambah Aman tidak menghapus tanggal yang tidak ada dalam file.
- Mode Ganti Rentang membackup data lama dan dapat di-rollback.
- Ringkasan baris, duplikat, store, periode, quantity, dan Rupiah harus diperiksa
  sebelum klik Konfirmasi Import ke MySQL.

RACING BULANAN
- Buka Admin > Program Racing Bulanan.
- Program dapat dibuat, diedit, dihapus, atau disalin dari bulan sebelumnya.
- Aturan dapat memakai brand, artikel, kategori, batas harga, quantity, atau Rupiah.
- Isi target per sales melalui menu Target per Sales.
- Perubahan langsung masuk dashboard tanpa mengubah coding.

CATATAN
- Apache tidak menjalankan aplikasi ini. XAMPP dipakai untuk MariaDB/MySQL.
- MySQL dinyalakan otomatis oleh shortcut jika belum aktif.
- Backup MySQL dibuat otomatis sekali sehari di folder backups (maksimal 30 file).
- Jangan menghapus folder aplikasi, data-awal, .env, node_modules, atau .next.
- Jika komputer diganti, pindahkan seluruh paket dan jalankan INSTALL_DASHBOARD.bat lagi.
- Sebelum memindahkan atau menghapus folder, klik "Tutup Sales Dashboard" dan
  tunggu pesan bahwa folder aman dihapus. Menutup tab browser saja tidak
  menghentikan server Node.js yang berjalan tersembunyi.
